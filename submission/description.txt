Kervan Credit Passport is an AI underwriting agent for small businesses in Mongolia that keep informal records. The owner uploads a photo of a handwritten sales ledger, a bank statement (PDF/CSV) and a payment-provider export; Kervan turns them into a verified, explainable credit passport a bank can act on. Gemini (gemini-3.8-flash via the google-genai SDK, structured JSON output) does four jobs: READ documents with evidence pointers, VERIFY declared figures against documents (merged with deterministic Python checks), EXPLAIN the result to the owner in English and Mongolian, and WRITE an underwriter credit memo. The score itself comes from a deterministic, unit-tested scorecard; the model never sets or changes it, and a number guardrail blocks invented figures. The FastAPI service and UI run on Cloud Run; Cloud Build builds it and Secret Manager holds the key; assessments are stored as JSON on the instance, with Firestore as the planned persistence layer. Banks see anonymized passports and make offers; the business controls identity disclosure.
